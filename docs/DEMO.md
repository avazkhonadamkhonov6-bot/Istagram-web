# Демонстрация frontend v0.2

Подготовка: запустить API с актуальными миграциями и frontend, войти двумя
пользователями в отдельных профилях браузера. Для локальной проверки используются
изолированные данные `apps/api/test/seed-frontend.cjs` (см. README).

1. На регистрации проверить занятый и свободный username.
2. В Edit profile изменить имя, username, bio и website; открыть обновлённый профиль.
3. В Create выбрать фото, caption, location и человека в Tag people; опубликовать.
4. У отмеченного пользователя открыть TAGGED и публикацию. Проверить ссылки
   mention/hashtag/location, лайк комментария и закрепление автором публикации.
5. В меню публикации проверить Edit, Hide like count, Turn off commenting,
   Pin, Archive/Unarchive и Delete с подтверждением.
6. Добавить публикацию в коллекцию; в Saved переименовать коллекцию, убрать
   публикацию и удалить коллекцию с подтверждением.
7. Опубликовать Story для Close friends. Посмотреть с другого аккаунта,
   поставить лайк, ответить и отправить историю в Direct. Автор открывает список зрителей.
8. Создать Highlight из истории в архиве, открыть, изменить и удалить.
9. В чужом профиле проверить Favorites, Restrict/Unrestrict, Mute/Unmute,
   Close friends и Report. В своей ленте переключить Following/Favorites.
10. Для приватного профиля отправить follow request и подтвердить его в Notifications.
11. Начать эфир из Create. У зрителя открыть эфир из Stories, Notifications
    и значка LIVE в профиле. Повторить навигацию на 375 px.
12. В своём списке Followers удалить подписчика. Перезагрузить страницу и
    проверить сохранённое состояние и отсутствие hydration/CSP ошибок.

Для звонков между разными сетями нужен отдельный прогон на двух физических
устройствах и, при необходимости, действующие TURN credentials. Это проверка
FE-30/инфраструктуры; localhost и проверка ссылок FE-31 её не заменяют.

Это маршрут локальной демонстрации. Публикация релиза и deploy не выполняются
самим этим документом.
