  использует закреплённый pnpm через npx, собирает shared и запускает web.

- Ответы `/api/*` с 504 через 60 секунд выдавал BFF при таймауте backend.

  `db=up`, `storage=up`. Исходный сетевой сбой не воспроизведён; точная причина
  задержки сервера по этому логу не устанавливается.
- Добавлены `npm run check:api` и сообщение о 502/504 с повторной попыткой.
  Таймаут не увеличивался, авторизация и защита BFF сохранены.

## Исправление загрузки разделов и hover-меню — 2026-10-22

Левая навигация занимает 72 px и показывает только иконки. При наведении
раскрывается до 245 px поверх содержимого; после ухода указателя снова
сворачивается. Для клавиатуры раскрывается при focus-visible. При открытой
панели поиска/уведомлений сохраняет узкую ширину. Содержимое страницы
не сдвигается; мобильная нижняя навигация сохранена.

Причина ошибок на новом скриншоте воспроизведена через локальный BFF:
ответы HTTP 200 содержали обрезанный JSON. После merge `f0e45d5` в прокси
вернулась передача исходного `Content-Length`. Render сжимает JSON Brotli,
а Node fetch автоматически его распаковывает. Например, заголовок ленты
сообщал 2456 байт, а распакованное тело занимало 11858 байт; браузер читал
только 2456 байт. Аналогично обрезались Reels и истории. В `e9c18b7`
заголовок уже исключался; merge восстановил его для поддержки медиа.

Теперь `Content-Length` передаётся только для несжатых ответов. Для
распакованных br/gzip/deflate удаляется. Видео продолжает получать
`Range`, `If-Range`, `Content-Range`, `Accept-Ranges` и корректную длину
несжатого диапазона. Авторизация и потоковая передача сохранены.
