## Xatohoe, ki dar QA yoft va islohshudand

1. **Log:** parol va kodi ivazi parol dar `req.url` (query) — url aknun bidun query navishta meshavad.
2. **BFF rate limit:** `/api/auth/login` IP-i mijozro ba API namefiristod → hamai userho yak limit-i 5/daq. doshtand (yak kas hamaro baste metavonist). Aknun `clientIp()` dar hamai route-ho.
3. **Offline:** paym dar offline "pending" memond, rollback va toast nabud → `networkMode: "always"`.
4. **Direct:** chati nav pas az "New message" dar ruyxat namoyon nameshud → `invalidateQueries`.
5. **POST → 201:** dar kontrakt hama 200 → interceptor-i global.
