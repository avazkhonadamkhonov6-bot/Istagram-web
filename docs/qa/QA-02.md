# QA-02 — frontend Abubakr

Дата: 2026-10-21. Основа проверки: Spec 10, действующие endpoint/DTO Spec 12–13.
Изменения ограничены frontend Abubakr и его документацией. Исходники API,
`packages/shared`, BFF routes, `proxy.ts`, socket/realtime, Direct, тесты и QA-01
Avaz не изменены.

## Реализовано

- FE-01–05: запуск Next.js 16, существующие токены Instagram, UI, MSW,
  sidebar 245/72 px, мобильная навигация, панели Search/Notifications.
- FE-06: формы, ошибки 409, debounce 400 ms, отмена устаревших проверок,
  нормализация username, блокировка невалидной формы. Ограничение live-проверки
  username до регистрации описано ниже.
- FE-07–08: carousel, double-tap like, optimistic like/save с rollback и toast,
  infinite scroll с размонтированием дальних карточек, приоритет первой фотографии,
  Share в Direct, копирование ссылки, подтверждение удаления собственного поста,
  post modal / отдельная страница, comments/replies и удаление комментариев
  автором комментария или поста.
- FE-09–10: профиль, счётчики, Follow/Following с optimistic rollback, Message,
  POSTS/REELS/SAVED, собственные saved, followers/following с поиском и состоянием
  подписки, avatar upload, bio 0/150, смена пароля.
- FE-11–12: Explore, hashtag, поиск и recent searches; уведомления с группами,
  thumbnail, Follow back, read-all и подключением существующего realtime badge.
- FE-14: те же компоненты работают без mocks через существующий BFF;
  данные профиля и поста загружаются на сервере и передаются в TanStack Query
  как initialData. Клиент получает только DTO, не JWT.
- FE-16: Stories tray/viewer, unseen/seen, progress, стрелки, hold/pause,
  Escape/Space, переход между пользователями, like, собственные view/like counts.
- FE-18: post/reel/story, drag & drop, 1–10 media, проверка MIME/размера/длительности,
  crop фото (original/1:1/4:5/16:9), carousel, caption, multipart upload, retry.
- FE-20: Reels, scroll snap, autoplay/pause по IntersectionObserver, mute,
  like/comment/share/save, double-tap, Follow, просмотр после двух секунд.
- FE-22: dark/system appearance с сохранением, доступные диалоги с focus trap,
  клавиатура, reduced motion, loading/empty/error/404, адаптация 1440/1000/390.
  Готовые WidgetBoundary Avaz подключены без изменения их реализации.

## Ограничения, требующие изменения контракта Avaz

Эти пункты не помечены выполненными и не имитируются в production UI.

| Код | Задача | Причина |
|---|---|---|
| API-FE-06 | Live username availability до регистрации | `/User/get-users` защищён авторизацией; публичного endpoint проверки нет. UI не выдаёт 401 за «username available», а оставляет окончательную проверку регистрации, включая 409. Mock-проверка с debounce работает. |
| API-FE-10 | Изменение username/fullName/website | `update-user-profile` принимает только `about`/`gender`; shared schema не содержит этих полей. Имя и username показаны read-only. |
| API-FE-09 | Remove follower | Endpoint удаления подписчика отсутствует в Spec 12–13. Follow/Unfollow доступны. |
| API-FE-16 | Список зрителей Stories | DTO содержит только собственные viewCount/viewLike; endpoint списка зрителей отсутствует. UI показывает реальные счётчики. |
| API-FE-18 | Location у поста | `add-post` и `PostDto` не содержат location; форма не показывает неработающее поле. |

Presign/S3, refresh token и обработка WebP исключены действующим Spec 12;
загрузка реализована multipart через API. Видео и GIF сохраняют исходный формат;
crop применяется к неподвижным фотографиям. Оптимизацию закрытых изображений
Next Image нельзя включать без изменения media-доступа: optimizer не передаёт
cookie пользователя. Реальная производительность измерена отдельно.

## Границы проверки

Lighthouse относится к локальному production-серверу с seed/QA-данными и desktop
профилем, а не к задержкам внешней сети/CDN. Responsive отдельно проверяется
при 1440/1000/390 px. Точное пиксельное совпадение со всеми страницами текущего
instagram.com не заявляется: сравнение сделано с требованиями Spec 10; чужой
аккаунт Instagram для reference-снимков не использовался. Backend AC из старых
Spec 02–07, заменённые Spec 12, не отмечаются как новые выполненные задачи Avaz.
