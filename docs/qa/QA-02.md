# QA-02 — frontend Abubakr

Дата: 2026-10-23. Основной прогон и Lighthouse — 2026-10-22; повторная проверка автоматического запуска и live regression — 2026-10-23. Проверяется актуальный локальный код поверх `origin/main`
`b83d30a`. Контракт: Spec 12–16 и дополнение FE-06/FE-10 в Spec 14 §9.

## Завершённые функции

- FE-06: публичная проверка username с debounce 400 ms, отмена устаревшего
  результата, нормализация, reserved/taken/unavailable, окончательная проверка
  уникальности при регистрации.
- FE-10: avatar upload/delete через multipart по Spec 12, bio, gender, изменение
  username и имени, website с проверкой HTTP(S); доступность нового username
  проверяется до сохранения. Backend возвращает 409 при конфликте, включая гонку.
- FE-16/FE-26: Stories — unseen/seen/Close friends, progress, hold/pause,
  клавиатура, like, reply, share в Direct, собственные зрители и лайки, удаление
  с подтверждением. Escape в окне зрителей закрывает только окно.
- FE-18/FE-26: Post 1–10 файлов, Reel, Story + Close friends, crop, caption,
  location, поиск людей и координаты отметок на фото. После закрытия очищаются
  media, object URLs и состояние публикации.
- FE-26: TAGGED с отдельным endpoint; Highlights из активных и архивных историй
  (создание, просмотр фото/видео, изменение состава/названия, удаление); private
  profile; Block, Restrict, Mute, Close friends, Favorites и Report.
- FE-26: Edit, Archive/Unarchive, Pin/Unpin, Hide/Show like count,
  Turn off/on commenting, Delete, Report и Add to collection в меню публикации.
  Collections в Saved: создание, просмотр, переименование, добавление/удаление
  публикации, удаление коллекции. Лайки/закрепление комментариев, ссылки
  @mention/#hashtag/location; отметки людей видны в detail публикации.
- FE-29: Remove follower; REELS профиля через отдельный endpoint; Pin comment;
  Following/Favorites feed; ссылки Privacy/Favorites/Activity; токены Spec 10.
- FE-31: Create → `/live/new`; Stories и Notifications → конкретный `/live/[id]`;
  LIVE на профиле; завершённый эфир из уведомления ведёт в каталог `/live`.
- FE-22/QA-02: исправлен overflow четырёх вкладок профиля на мобильном;
  SSR передаёт состояние своего профиля, Highlights и первую страницу сетки,
  чтобы при hydration не сдвигалось содержимое.

## Границы результата

Проверки выполняются на отдельном PostgreSQL на localhost; общая база Render
не изменялась. Дополнение FE-06/FE-10 требует deploy API вместе с новой миграцией
`20261022200000_profile_website`, затем обновления frontend.

Lighthouse относится к локальным QA-данным и desktop, а не к внешней сети или
полному seed с сотнями видео. Точное пиксельное совпадение с каждой страницей
instagram.com не заявляется.

WebRTC между физическими компьютерами в разных сетях и реальные TURN credentials
проверяются отдельно в FE-30/инфраструктуре. Проверка ссылок FE-31 подтверждает
доступность нужного маршрута и не подменяет такую проверку связи.

Redis/BullMQ, presign/S3, WebP worker и refresh token были вынесены из текущего
MVP в Spec 12. Они не входят в завершённые frontend-задачи и не отмечены
выполненными этим отчётом.
